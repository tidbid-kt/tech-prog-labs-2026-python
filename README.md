# Шаблон репозитория для лабораторных работ по курсу Технологии программирования 2026 (Python)

## Окружение

1. **Python 3.10 или новее**: [скачать тут](https://www.python.org/downloads/);
2. **PyCharm Community** или **VS Code** с расширением Python.

## Как начать работу с проектом

1. Сделайте fork к себе на GitHub (инструкция [тут](https://docs.github.com/ru/pull-requests/how-tos/work-with-forks/fork-a-repo)).
2. Склонируйте свой fork и откройте папку проекта в IDE.
3. Можно приступать к работе!

Если у вас уже есть свой репозиторий с прошлыми лабами, форк делать не обязательно: можно скопировать к себе нужные
папки из этого репозитория.

## Структура пакетов

Для каждой лабораторной работы выделен отдельный пакет:

| Пакет       | Лаба   |
|-------------|--------|
| `labs/lab2` | Лаба 2 |
| `labs/lab3` | Лаба 3 |
| `labs/lab4` | Лаба 4 |
| `labs/lab5` | Лаба 5 |
| `labs/lab6` | Лаба 6 |
| `labs/lab7` | Лаба 7 |

В каждом пакете уже заведен шаблонный `main.py`. Модули внутри пакета лабы удобно импортировать относительными
импортами (`from .hero import Hero`).

## Как запустить код

Все команды выполняются из корня репозитория. Модуль запускается по полному имени, например программа лабы 2:

```bash
python -m labs.lab2.main
```

Так же запускается любой другой модуль лабы, например `python -m labs.lab3.demo`.

## После выполнения лабораторной

После выполнения лабораторной работы необходимо закоммитить и запушить итоговый код.

Коммиты будут идти в ваш fork, не в оригинальный репозиторий.

При появлении изменений в оригинальном репозитории на GitHub откройте свой fork и нажмите кнопку **Sync fork** после чего выполните `git pull` в терминале.
